# SyntaxWear - E-commerce de Tênis e Sneakers

Bem-vindo ao repositório do **SyntaxWear**, um projeto de e-commerce moderno focado na venda de calçados (tênis e sneakers). Este projeto foi desenvolvido com foco em design responsivo, organização modular de CSS e uma experiência de usuário limpa e intuitiva.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias fundamentais da web:

- **HTML5**: Estrutura semântica para melhor acessibilidade e SEO.
- **CSS3**: Estilização avançada com uso de variáveis, Flexbox e Grid Layout.
- **Design Responsivo**: Adaptado para diferentes tamanhos de tela (Mobile First).

## ✨ Funcionalidades

- [x] **Header Responsivo**: Menu hamburguer funcional (Mobile) e navegação completa para Desktop.
- [x] **Seção Hero**: Destaque principal para lançamentos (ex: Krypton One).
- [x] **Categorias**: Filtros visuais para estilos como Casual, Esporte, Moderno e Futurista.
- [x] **Grade de Produtos**: Layout em grid para exibição de modelos e destaques.
- [x] **Newsletter**: Área para captura de e-mails no rodapé.
- [x] **Rodapé Completo**: Links de navegação, redes sociais e informações de copyright.

## 📁 Estrutura do Projeto

A organização dos arquivos segue uma lógica modular para facilitar a manutenção:

```text
syntax-wear-ecommerce/
├── css/                # Estilos globais e variáveis
│   ├── components/     # Estilos específicos de cada componente (Header, Footer, etc.)
│   ├── base.css        # Estilos base de elementos
│   ├── reset.css       # Reset de estilos do navegador
│   ├── variables.css   # Definição de cores e fontes (Custom Properties)
│   └── style.css       # Agregador de estilos
├── images/             # Ativos visuais (Logos, Ícones e Fotos de Produtos)
├── js/                 # Scripts (em desenvolvimento)
├── index.html          # Página principal do site
└── README.md           # Documentação do projeto
```

## 🛠️ Como Executar o Projeto

Como este é um projeto estático (HTML e CSS), você pode visualizá-lo de forma muito simples:

1. Faça o clone deste repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge, etc.).
3. **Dica**: Se estiver usando o VS Code, recomendo a extensão **Live Server** para visualizar as alterações em tempo real.

## 🎨 Design e Estilo

O projeto utiliza uma paleta de cores moderna e tipografia voltada para o público jovem e urbano. As variáveis CSS em `css/variables.css` facilitam a alteração global de cores e temas.
